# Country Data Collector

A Python project that retrieves country information
from an API and allows users to search, display,
save, and load country data.

## Features

- Fetch country data from an API
- Display country information
- Search for a country
- Save country data in JSON format
- Load saved country data
- Handle common network errors
- Handle missing country information

## Technologies Used

- Python
- Requests
- JSON
- REST API

## Requirements

- Python 3
- Requests library
- An API key, if required by the API provider

## Installation

Install the required library:

pip install -r requirements.txt

## API Configuration

Obtain an API key from the API provider if required.

Configure your key locally before running the program.

Never publish your actual API key.

## How to Run

Run the Python program:

python country_data.py

## Offline Testing

The sample country.json file can be used
to test saved-data features without making
additional API requests.
